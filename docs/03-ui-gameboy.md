# Game Boy UI Specification

## Visual Style

- Monochrome or limited green palette
- Pixel or retro-style font
- Screen-like container
- Directional navigation feel

## Layout

- Left panel: Pokémon list
- Right panel: Pokémon details
- Screen frame visible at all times

## Interaction

- Click or keyboard navigation
- Clear focus state
- No modern UI patterns (no cards, no glassmorphism)
