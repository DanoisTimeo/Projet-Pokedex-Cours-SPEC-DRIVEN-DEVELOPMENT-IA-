# Introduction

This application is a **Pokédex**, inspired by classic Game Boy interfaces.

The goal is to allow users to browse, search, and consult detailed information
about Pokémon using the public PokeAPI.

## Core Features

- Display a scrollable list of Pokémon
- Search Pokémon by name or ID
- View detailed Pokémon information
- Retro Game Boy inspired UI
- No authentication required
- Client-side only application

## Target Experience

The application should feel like using an old handheld Pokédex:
simple, readable, and focused on information rather than animations.
